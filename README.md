# Instagram Info Tool

Python tool to get Instagram public user information.

## Features
- Username
- Full Name
- Bio
- Followers
- Following
- Posts
- Verified Status
- Profile Picture
- External Link

## Installation

git clone https://github.com/Kinghacker009/instagram-info-tool

cd instagram-info-tool

pip install -r requirements.txt

## Run

python insta_info.py
